# Batting distribution report

Generated by `npm run report:batting` from the game's own simulation code: each row is 200 simulated deliveries (each with its own execution error) and strokes. "Aerial chance" = the ball was above 0.3 m more than 12 m from the bat before bouncing (a catchable chance, before fielders are modelled). Directions are degrees from straight, positive towards the off side.

The report shows the shape of the model; it is not evidence of realism by itself.
